# SecondBrain

My notes on computer science, maths, neuroscience and finance, kept in Obsidian from 2021 to 2026. There are about 840 of them, and they got me through a Bachelor of Computer Science.

**Status:** Archived. I've switched to handwritten notes, so this vault is no longer updated.

## Topics

- Programming concepts, C and C++
- Mathematics
- Machine learning and AI
- Neuroscience and brain-computer interfaces, including summaries of 38 papers in `Notes/Papers/`
- Investing and financial products
- React Native and Qt/QML
- Quantum computing

Most notes are casual and stream-of-consciousness, written to get a quick high-level grip on a subject. Others are short point-form summaries. Notes on the harder topics may include swearing.

## Usage

The notes are plain Markdown, so you can read them on GitHub or in any editor. To follow the links between them, open the folder as a vault in [Obsidian](https://obsidian.md/):

```sh
git clone https://github.com/Carter-FS/SecondBrain.git
```

Then choose "Open folder as vault" in Obsidian and select `SecondBrain`.
